# Foundry Screenshot Guide

The README uses the supplied Microsoft Foundry screenshots:

| File | Screen |
|---|---|
| `foundry-evaluation-criteria.png` | Evaluation criteria with agent/tool, quality, and safety evaluators |

To refresh them, capture the equivalent screens from the deployed Foundry project after `npm run azure:deploy` completes. Sanitize tenant, subscription, identity, prompt, and trace information before committing new screenshots.
